# GNI Solution — QA 증명서 진위확인

지엔아이솔루션(주) 품질보증부에서 발급한 증명서의 **발급 사실**을 확인하는 페이지입니다.

## 공개 주소

- 포털 : https://gnisol.github.io/qa-verify/
- 경력증명서 : https://gnisol.github.io/qa-verify/career_verify.html

## 파일 구성

| 파일 | 설명 | 갱신 |
|------|------|------|
| `index.html` | 진위확인 포털 | 고정 |
| `career_verify.html` | 경력증명서 조회 페이지 | 고정 |
| `gni_career_db.json` | 발급기록(공개용) | **발급 시마다 갱신** |

## 갱신 절차

1. 경력증명서 생성기에서 PDF 다운로드 (발급이력 자동 기록)
2. `① 공개용 gni_career_db.json` 버튼으로 파일 내려받기
3. 본 저장소의 `gni_career_db.json` 을 교체 후 커밋
4. 1~2분 뒤 GitHub Pages 반영 확인

## 개인정보 처리

- 공개 JSON에는 **발급번호 / 조회코드 / 발급일 / 유형 / 마스킹 성명 / 총일수 / 기재건수** 만 포함됩니다.
- **주민등록번호, 성명 전체, 프로젝트 상세, 제출처, 주소는 포함되지 않습니다.**
- 발급번호 열거로 타인 기록을 조회하는 것을 막기 위해 8자리 **조회코드** 일치를 요구합니다.
- 전체 내역은 사내 발급대장 CSV로만 보관하며 외부에 공유하지 않습니다.
